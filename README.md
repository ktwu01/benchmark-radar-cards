# Benchmark Radar cards

Share images for [Benchmark Radar](https://benchmark-radar.org). Each image shows who made a benchmark, when it appeared, and what it tests.

| Branch | Contents |
| --- | --- |
| `daily/<YYYY-MM-DD>` | That day's `top3.png` and one `card-NN.png` per benchmark in the daily briefing |
| `cards` | One card per benchmark in the Benchmark Radar catalog |

The [benchmark-radar](https://github.com/ktwu01/benchmark-radar) workflows generate these images. Do not edit them by hand.
